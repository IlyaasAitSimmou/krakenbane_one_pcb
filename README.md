This project involves the development of a data acquisition (DAQ) flight computer to be used on a model rocket for the Launch Canada competition. The computer includes an STM32H753 microcontroller, BNO086 inertial measurement unit, BMP581 barometric pressure sensor, ADXL367 high-g accelerometer, BME688 environmental sensor, and a microSD reader.

The project is also my first PCB design using SMT components. I have dedicated dozens of hours and sought support from university rocketry team members.
